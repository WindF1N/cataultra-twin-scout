# Operator Manual

## Запуск

```bash
.venv/bin/python main.py
```

## Меню

- `🧬 Запустить Twin Scout Daemon` — бесконечный 24/7 цикл.
- `🔁 Один цикл сбора` — один проход по рынку для проверки доступа.
- `📊 Проанализировать текущую сессию` — ручной запуск корреляционного анализа.
- `⚙️ Показать конфиг` — текущие параметры.
- `❌ Выход` — завершение.

## Настройка автономности

```bash
TWIN_SPEED_MODES="*"              # все типы монет без фильтра speedMode
TWIN_WORKER_COUNT=5               # количество параллельных fair-data воркеров
TWIN_REQUEST_DELAY_MIN_SEC=0.2
TWIN_REQUEST_DELAY_MAX_SEC=1.2
TWIN_RETRY_MAX_ATTEMPTS=4
TWIN_RETRY_BACKOFF_BASE_SEC=1.0
TWIN_RETRY_BACKOFF_MAX_SEC=30.0
```

Если сервер отвечает `429` или временной `5xx`, клиент делает backoff с джиттером и повторяет запрос. Если падает весь цикл сбора, 24/7 демон пишет ошибку в консоль, ждет `TWIN_SCAN_INTERVAL_SEC` и продолжает работу со следующим циклом.

## Остановка

Нажать `Ctrl+C`. Демон сохраняет `state.json` после каждого завершенного цикла сбора.
