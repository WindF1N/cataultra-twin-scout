# Starter Skills

Локальные правила проекта, перенесенные из основного контура:

- `karpathy-guidelines`: простая проверяемая реализация без лишних абстракций.
- `api-and-interface-design`: стабильные контракты между API, storage и analyzer.
- `senior-data-engineer`: JSONL/JSON артефакты, воспроизводимость, batch lifecycle.
- `test-driven-development`: математика и модели покрываются unit-тестами.
- `documentation-and-adrs`: любые изменения storage contract фиксируются в `docs/`.
