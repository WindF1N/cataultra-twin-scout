# CATAULTRA Twin Scout Agent Rules

## Назначение

Этот проект является автономной read-only утилитой для сбора и анализа раскрытых траекторий Catapult-токенов.

## Строгие границы

- Не добавлять торговое исполнение.
- Не открывать и не закрывать позиции.
- Не менять баланс аккаунта.
- Не смешивать CLI, GraphQL, storage и математический анализ в одном модуле.
- Сохранять raw payload до нормализации.

## Стиль

- Кодовые идентификаторы — на английском.
- Документация и операторские сообщения — на русском.
- Любая новая модель данных должна иметь тест.
- Любая новая математика должна иметь тест.

## Definition of Done

- Изменение реализовано.
- Обновлена документация, если меняется контракт.
- Запущены тесты.
- Создан локальный commit.
